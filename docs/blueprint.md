# **App Name**: Cloudy

## Core Features:

- Real-Time Local Weather: Display hyper-local, real-time weather conditions including current temperature, 'feels-like' temperature, humidity, wind speed, UV Index, and Air Quality Index (AQI) based on user's GPS.
- Hourly & Daily Forecasts: Provide detailed hourly forecasts for the next 24 hours and a summary of conditions for the next 7 days, including temperature ranges and rain probability.
- Multi-Location Management: Allow users to automatically detect their current location, as well as add, save, and switch between multiple preferred locations for weather monitoring. These preferences will be stored persistently.
- AI Weather Insight Engine: A generative AI tool that analyzes weather conditions, time of day, and user location to provide human-like suggestions and actionable insights (e.g., 'Light rain expected at 3 PM — take an umbrella').
- AI Travel & Planning Assistant: A generative AI tool to suggest optimal times for outdoor activities or provide weather summaries tailored for upcoming trips, helping users plan effectively.
- Basic AI Voice Weather Query: Allow users to ask basic weather questions via voice (e.g., 'Will it rain today?'), with responses generated by the AI.
- Severe Weather Alerts: Implement a system to deliver severe weather warnings (e.g., storm warnings, flood alerts, heatwaves) to the user via web push notifications, providing critical and timely information.

## Style Guidelines:

- Primary Color: A serene, medium blue (#6699CC) that embodies calmness and clarity, reflecting the app's clean design philosophy and offering excellent contrast.
- Background Color: A very subtle light blue-gray (#F0F4F8) that maintains a calm and spacious feel, contributing to the minimal aesthetic and allowing content to stand out.
- Accent Color: A soft, gentle periwinkle/lavender (#9E9FFF) used for highlights, interactive elements, and to introduce a touch of visual distinction without overwhelming the serene palette.
- Text Color: Near-black dark gray (#333333) for main content to ensure readability and align with the modern, clean aesthetic.
- Dynamic backgrounds to visually represent current weather conditions (e.g., warm tones for sunny, cool blue-gray for rainy, deep blue for night) providing an intuitive visual experience.
- Body and Headline font: 'Inter', a modern, objective sans-serif that aligns with a clean, minimal, and data-focused design, ensuring clarity and readability across all text.
- Use clean, minimalistic, and scalable SVG-based icons. Incorporate subtle animations for weather icons to visually represent current conditions effectively and engagingly.
- Prioritize generous whitespace and a clear content hierarchy inspired by Apple iOS design. Layout elements should include centered location/temperature displays, rounded cards for AI insights, horizontal scrolling for hourly forecasts, and vertical lists for daily forecasts.
- Implement smooth transitions between sections and subtle animations for UI elements (e.g., loading states, interactive cards) to enhance the user experience without being distracting.
